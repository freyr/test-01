Git obsługujesz poleceniami wpisywanymi w wierszu poleceń (inaczej: terminal, konsola). Na początku wygląda to trudno, ale wystarczy kilka poleceń.

Jak otworzyć terminal

  • Windows: zainstaluj Git ze strony git-scm.com (lekcja 4). Instalator dodaje program Git Bash. Otwórz menu Start i wpisz Git Bash. W folderze możesz też kliknąć prawym przyciskiem myszy i wybrać Open Git Bash here.
  • macOS: naciśnij Cmd + Spacja, wpisz Terminal i naciśnij Enter.
  • Linux: naciśnij Ctrl + Alt + T.

Wszystkie przykłady na tych stronach pochodzą z Git Bash. W Terminalu na macOS i Linuksie polecenia są takie same.

Jak czytać okno terminala

Każda linia zaczyna się od znaku zachęty (ang. prompt). Pokazuje on, w którym folderze jesteś. Znak ~ oznacza Twój folder domowy, na przykład C:\Users\John. Po znaku $ wpisujesz polecenie i naciskasz Enter. Pod spodem pojawia się wynik.

~/Documents $ mkdir informatyka
# ↑ folder        ↑ polecenie, które wpisujesz

Nie przepisuj znaku zachęty ani $. Wpisuj tylko pogrubiony tekst.

Przykład

John sprawdza, gdzie jest, wchodzi do Dokumentów, tworzy folder informatyka, wchodzi do niego i wraca:

{{sesja terminal}}

Zwróć uwagę:

  • Polecenia cd i mkdir nic nie wypisują. Brak komunikatu oznacza, że wszystko się udało.
  • Znak zachęty zmienia się po każdym cd. Zawsze widzisz, w którym folderze jesteś.
  • W Git Bash dysk C: ma ścieżkę /c/, a ukośniki są w prawą stronę: /c/Users/John.

Dwa skróty, które oszczędzają czas

  • Tab: wpisz cd Doc i naciśnij Tab. Terminal sam dopisze Documents/. Mniej pisania i brak literówek.
  • ↑: strzałka w górę przywraca poprzednie polecenie. Naciśnij ją kilka razy, aby cofnąć się dalej.
Wielkość liter ma znaczenie. cd documents może nie zadziałać, gdy folder nazywa się Documents. Używaj Tab, a nie pomylisz się.
Spacje w nazwach sprawiają kłopot. Nazywaj foldery bez spacji i bez polskich znaków: zadania-html, a nie Zadania z HTML.

Ćwiczenie

  1. Otwórz terminal i wpisz pwd.
  2. Wpisz ls i znajdź folder Documents (lub Dokumenty).
  3. Wejdź do niego poleceniem cd z klawiszem Tab.
  4. Utwórz folder informatyka i wejdź do niego.
  5. Wróć do folderu domowego jednym poleceniem.

Sprawdź się

Jesteś w ~/Documents/informatyka. Gdzie będziesz po cd ..?

W ~/Documents.

Polecenie mkdir test nic nie wypisało. Czy to błąd?

Nie. Brak komunikatu oznacza sukces. Sprawdź poleceniem ls.

Jak powtórzyć poprzednie polecenie bez pisania?

Naciśnij strzałkę w górę, a potem Enter.
