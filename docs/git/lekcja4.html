Dodatek: Git i GitHub Lekcja 4 z 8

Instalacja i pierwsza konfiguracja Gita

Git trzeba zainstalować i raz skonfigurować. Konfiguracja na danym komputerze zostaje na zawsze.

Instalacja

  • Windows: pobierz instalator z git-scm.com/downloads. W instalatorze zostaw ustawienia domyślne i klikaj Next. Na jednym ekranie możesz wybrać edytor. Wybierz Notepad lub Visual Studio Code zamiast domyślnego Vim.
  • macOS: w Terminalu wpisz git --version. Jeśli Gita nie ma, system sam zaproponuje instalację narzędzi (Command Line Tools).
  • Linux: sudo apt install git (Ubuntu, Debian).

Na komputerze szkolnym Git może już być. Sprawdź to poleceniem git --version.

Kim jesteś: imię i e-mail

Każdy commit zapisuje autora. Git musi wiedzieć, jak się nazywasz. Bez tego nie zrobi commita. Podaj ten sam e-mail, co na koncie GitHub. Wtedy GitHub połączy commity z Twoim kontem i pokaże przy nich Twój awatar.

~ $ git --version
git version 2.51.0.windows.1
~ $ git config --global user.name "John Doe"
~ $ git config --global user.email "john.doe@example.com"
~ $ git config --global pull.rebase true
~ $ git config --global --list
user.name=John Doe
user.email=john.doe@example.com
pull.rebase=true

Co znaczą te polecenia:

  • git config zmienia ustawienia Gita. --global oznacza: dla wszystkich repozytoriów tego użytkownika na tym komputerze.
  • user.name i user.email to autor commitów. Cudzysłów jest potrzebny, bo w John Doe jest spacja.
  • pull.rebase true ustala, jak git pull łączy Twoje commity z commitami z GitHuba. Lekcja 8 pokazuje, kiedy to ma znaczenie. Bez tego ustawienia Git czasem otwiera edytor albo wypisuje długie ostrzeżenie.
  • --list pokazuje wszystkie ustawienia. Tak sprawdzisz, czy nie ma literówki.
Komputer szkolny jest wspólny. Jeśli po Tobie pracuje inna osoba, jej commity zapiszą się z Twoim imieniem. Na koniec lekcji usuń swoje dane: 
~ $ git config --global --unset user.name
~ $ git config --global --unset user.email

Gdy otworzy się dziwny edytor

Jeśli wpiszesz git commit bez opisu -m "...", Git otworzy edytor, w którym masz napisać opis. Domyślny edytor to Vim. Wygląda jak czarny ekran z falkami ~ i nie reaguje normalnie na klawisze.

Jak wyjść z Vima:

  1. Naciśnij i. Teraz możesz pisać. Wpisz opis commita w pierwszej linii.
  2. Naciśnij Esc.
  3. Wpisz :wq i naciśnij Enter. Commit się zapisze.

Aby zrezygnować z commita, zamiast :wq wpisz :q!. Najprościej jednak zawsze pisać -m "opis".

Ćwiczenie

  1. Sprawdź wersję Gita.
  2. Ustaw swoje imię i nazwisko oraz e-mail z konta GitHub.
  3. Ustaw pull.rebase na true.
  4. Wyświetl ustawienia i sprawdź, czy nie ma literówek.

Sprawdź się

Dlaczego e-mail w Gicie powinien być taki sam jak na GitHubie?

GitHub łączy commity z kontem po adresie e-mail. Inny adres oznacza, że commity nie pokażą się jako Twoje.

Co znaczy --global?

Ustawienie działa we wszystkich repozytoriach tego użytkownika na tym komputerze.

Otworzył się Vim. Jak zapisać i wyjść?

Esc, potem :wq i Enter.
